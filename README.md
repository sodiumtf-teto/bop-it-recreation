# Bop It Remake:
A recreation of a bop it toy's logic as well as a twitch bot that allows users to send bop it prompts via chat command.

# TECHNICAL FEATURES:
- Two-way serial communication
- State management
- Input debouncing
- Noise tolerance, adjustable thresholds
- Mode switching
- Twitch bot integration
- Persistent scoring
- Dynamic difficulty
